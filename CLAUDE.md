# Image Flow Studio

Local node-based image editing canvas (React Flow + Gemini). See README.md for
architecture and how to run it.

## Workflow

- After making a code edit or adding a new feature in this repo, commit it
  with a short descriptive message (no need to ask first each time), then
  push it to origin/main right away. The repo is public
  (github.com/yuxa94/image-flow-studio) and the user uses the commit
  history for teaching, so each commit should land on GitHub promptly
  rather than sitting local.
