Image Flow Studio · 1주차 바이브 코딩 실습 프롬프트

사용법
1. image-flow-studio 폴더를 연 Claude Code(Code 탭) 입력창에 프롬프트를 통째로 복사해 붙여넣습니다.
2. Claude가 무엇을 할지 읽고 허용을 누릅니다.
3. 결과가 다르면 '안 되면' 아래 문장을 그대로 붙여넣습니다.
4. 수업은 week1-start 브랜치에서 시작합니다. Canvas 노드 완성본은 main 브랜치에 있습니다.


01 · .env 만들기 · 5분 · 수업용 브랜치로 바꾸고 .env 파일을 만듭니다
image-flow-studio 폴더를 수업용 week1-start 브랜치로 바꿔줘.
server/.env.example을 복사해서 server/.env 파일을 만들고 메모장(맥은 텍스트 편집기)으로 열어줘.
API 키는 내가 파일에 직접 붙여넣을 거니까 채팅으로 키를 물어보지 마.
.env가 .gitignore에 들어 있어서 깃에 안 올라가는지도 확인해줘.

안 되면
브랜치를 못 찾거나 .env 파일이 안 보여. git fetch로 브랜치를 다시 받고, 숨김 파일 설정 때문인지 확인해서 .env를 열어줘.

02 · 앱 실행 · 5분 · 설치하고 내 노트북에서 앱을 띄웁니다
이 프로젝트를 실행해줘.
맨 위 폴더에서 npm install, 그다음 npm run install:all로 필요한 블록을 설치하고 npm run dev로 켜줘.
서버(3001)와 화면(5173)이 둘 다 떴는지 확인하고, 브라우저로 열 주소를 알려줘.
.env의 Gemini 키가 읽혔는지도 확인하되 키 값은 화면에 보여주지 마.

안 되면
localhost가 안 열려. 터미널 오류 원문을 읽어서 원인을 알려줘. 포트를 다른 프로그램이 쓰고 있으면 그 프로그램은 끄지 말고 나한테 먼저 물어봐.

----------------------------------------

03 · 기능 개선 · 15분 · 파일을 끌어다 놓으면 Image 노드가 생기게 합니다
지금은 이미지를 넣으려면 Image 노드를 만들고 Upload 버튼으로 파일을 찾아야 해서 불편해.
내 컴퓨터의 이미지 파일을 캔버스 빈 곳에 끌어다 놓으면 그 자리에 Image 노드가 생기고 그림이 바로 들어가게 해줘.
이미 있는 Image 노드 위에 놓으면 그 노드의 그림만 바뀌게 해줘.
왼쪽 목록에서 노드를 끌어오는 기존 기능은 그대로 둬.
고치기 전에 바꿀 파일을 먼저 알려주고, 끝나면 내가 확인할 순서를 알려줘.

안 되면
파일을 놓으면 브라우저가 새 탭으로 그림을 열어버려. 드롭의 기본 동작을 막고 있는지 확인하고 고쳐줘.

----------------------------------------

04 · Canvas 노드 · 1단계 · Canvas 노드 1단계: 노드와 브러시를 만듭니다
이미지 위에 표시를 그릴 수 있는 Canvas 노드를 새로 만들어줘.
Crop 노드를 참고해서 같은 모양으로 만들고, 왼쪽 목록 TOOL에 Canvas를 추가해줘.
왼쪽 점에 이미지를 연결하고 '그리기' 버튼을 누르면 큰 창이 열리고, 마우스로 드래그하면 빨간 선이 그려지게 해줘.
'적용'을 누르면 선이 합쳐진 이미지가 노드에 보이고, 오른쪽 점으로 다음 노드에 넘어가게 해줘.
선은 원본 이미지 해상도 기준으로 저장해줘.

안 되면
적용했더니 선 위치가 내가 그린 곳과 달라. 화면에 보이는 크기와 원본 이미지 크기의 비율로 좌표를 바꾸고 있는지 확인해줘.

----------------------------------------

04 · Canvas 노드 · 2단계 · Canvas 노드 2단계: 펜, 색, 되돌리기를 더합니다
Canvas 그리기 창에 도구를 더해줘.
브러시(B)와 펜(P)을 고를 수 있게 하고, 펜은 클릭한 점을 직선으로 잇다가 Enter나 더블클릭으로 끝나게 해줘.
색 6개와 굵기 슬라이더를 넣고, Ctrl+Z(맥은 Cmd+Z)로 한 획씩 되돌리게 해줘.
창을 다시 열면 그렸던 선이 남아 있어서 이어서 고칠 수 있게 해줘.
끝나면 '캔버스 노드 추가'라는 메시지로 커밋해줘. push는 하지 마.

안 되면
그리기 창에서 Delete나 방향키를 누르면 뒤에 있는 노드가 지워지거나 움직여. 창 안의 키 입력이 캔버스로 넘어가지 않게 막아줘.
